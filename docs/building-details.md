# 建筑详情与统一过渡

主城中的全部建筑共用 `BuildingDetailTransition` 与 `BuildingDetailPresenter`。
点击建筑由 `CityViewport.BuildingSelected` 分发，界面通过 `UIBindings` 取得组件，不在预制体上序列化热更脚本。

## 过渡流程

点击建筑后立即弹出详情：详情页从 1.3 倍缩放至 1 倍，并在 300ms 内从 50/255 淡入至完全显示，不等待或执行地图聚焦。
关闭时详情页在 300ms 内缩向点击建筑的位置。整个打开和关闭过程均不改变地图的中心、相机位置或缩放。
过渡使用不受 Time.timeScale 影响的时间。窗口关闭、取消或销毁会终止协程、隐藏详情并恢复输入，避免迟到动画重新打开界面。
节奏参考旧客户端 `appClient/logic/city/city.sd` 的 `open_build` 与 `appClient/logic/build.sd` 的关闭逻辑。

## 内容与资源

- 全部建筑由 `BuildingPreviewViewport` 从主城预制体提取被点击的建筑单独渲染，不包含周围建筑；保留原资源父级旋转与缩放，按实际可见像素裁掉透明留白，保持宽高比。
- 展示区没有固定框尺寸，按建筑比例与屏幕可用空间自适应，升级详情紧接在建筑下方；标题、说明和升级效果由 `BuildingDetailDefinition.For` 集中配置。
- 联盟和领地入口仅在城主府显示，使用同一组深色金边圆形图标和公共提示弹层。
- 任务黑框与返回登录按钮已从主城预制体生成逻辑移除。
- 数值、资源消耗与升级提示均为标明的本地演示数据；联盟、领地和升级操作没有发起服务端请求，也不会改变资源或等级。

UI 按 1080×1920 竖屏制作，背景覆盖全帧，交互内容继承窗口原有 SafeArea。720×1280 与 1080×2400 也有独立渲染截图。

## 视觉样式

详情 UI 使用全屏三国主题背景：青灰山城、松影与暗金边饰围绕浅色留白，原主城视角保持不动。名称、等级下方直接展示所选建筑，升级说明和收益接在其下，内容保留左右留白。金币、银锭、铁、木、粮存量统一放在安全区内下移的顶部宣纸细金框区域，朱漆升级按钮作为主操作。城主府的联盟/领地入口放在升级区标题右侧，公共提示弹层沿用白石与朱漆样式。
文字、数值和命中区域保持原生 UGUI 组件，可独立编辑，不烘焙到整张背景中。新生成素材与提示词位于 `Assets/Content/UI/MainCity/Art/Refined`。

## 主城 MainUI

MainUI是全屏拉伸的UGUI根节点，采用顶部资源、底部角色操作的分区。Top高160参考像素，显示金、银、铁、木、粮；Bottom高268参考像素，包含头像、等级、贵族、角色名、战力、经验数值与进度条及功能按钮。交互内容遵循现有安全区，青墨半透明渐隐底色向安全区外延伸，取自主城树林与青瓦色调。中间城池区域可继续拖拽和缩放。功能按钮展开武将、背包、联盟、领地入口；头像打开主公信息。尚未接入服务的入口显示本地说明。

Game层通过`UIMainCity.SetPlayerInfo(MainCityPlayerInfo)`刷新角色数据，并同步MainUI及建筑详情的资源存量。当前默认数据是本地体验值，没有服务器角色身份。`MainCityHudPresenter`负责绑定、弹层、数据更新和解绑；`MainCityHudUIBuilder`生成布局与原生渐变素材，随`Build Main City UI`统一生成。打开任意建筑前关闭MainUI弹层，公共过渡组件隐藏整层CityHud，返回后恢复。
