# 三国策竖屏登录界面

设计基准为 1080×1920，只支持竖屏。继续使用现有 UILogin 窗口、UIService、原生绑定和 ISessionClient，不新增启动或网络体系。

## 美术与布局

- 主视觉为用户最新提供的“三国策”战场插画，原始文件保存在 Assets/Content/UI/Login/Art/ThreeKingdomsWar.png。
- 当前原图 SHA-256：FAE8B3962EB3CAD93E4BBF6476925D08D2C4B82E1086953E2D01B46F4B66E6DB；直接复制原文件，未修改像素。
- 参考用户第二张图的下方区服条、朱红金边进入按钮及协议确认排布。
- 插画以中心为基准等比覆盖画面，超出部分对称裁切；底部独立渐暗，交互内容使用现有安全区。
- 操作区集中在屏幕底部。登录前显示账号、密码和“登录”；登录成功后隐藏输入区，显示服务器条和“进入游戏”。
- 主按钮居中，设计尺寸为 276×96，宽度约为原 826 宽按钮的三分之一；字号 40，保留朱红底和简化金边。
- 账号、密码输入行和登录后的默认服务器栏均为 552 宽，即登录按钮的两倍，保持居中对齐。
- 输入行与默认服务器栏共用黑底、双层金边和四角纹饰，内部文字避开角饰并保留直接输入交互。
- 输入内容与密码占位提示在各自输入区域内水平、垂直居中，左侧字段标签保持原位。
- 不增加横屏布局；正式构建关闭横屏自动旋转。

## 当前交互

- 账号可直接点击输入。密码控件为演示布局，当前会话协议不支持密码认证，因此密码不读取、不发送、不记录，界面提示无需真实密码。
- 点击“登录”调用现有登录会话，成功后切到选服与进入阶段；随后点击“进入游戏”打开 UIMainCity。保留本地模拟与 Tok 开发登录的真实状态说明。
- 服务器条只展示当前默认区服；当前没有服务端区服目录，未启用虚构的选服功能。
- 协议勾选按参考图默认选中；取消勾选后不允许发起登录请求。
- 连接中显示取消操作；原有拒绝、超时、断线、关闭后迟到结果及事件释放逻辑保留。
- 已测量软键盘完全覆盖底部表单时，现有键盘控制器将可用视口移至键盘上方；关闭后恢复原位。登录页在键盘可见但未提供几何时，临时扩展到安全区并允许手动滚动，不猜测键盘高度；其它窗口默认保持原策略。
- 协议标题目前为界面文案，未加入正式协议内容或外部链接。

## 制作与预览

登录美术生成方法保留在 LoginArtworkBuilder.Apply，专项菜单入口已移除。日常布局直接编辑登录Prefab，绑定代码由UIBindingGenerator生成。

LoginArtworkBuilder.Capture仍可通过编辑器脚本调用，预览输出到Builds/LoginUI。日常预览使用Game/UI/Preview。
